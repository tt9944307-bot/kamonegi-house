# カモネギハウス 3D 🦆🌿

Apexクラン「カモネギハウス」の家を three.js で再現した3Dシーンです。メンバーのカモ15羽が、それぞれの好物を背負って暮らしています。ブラウザでぐるっと回して遊べます。

▶ **遊ぶ：https://tt9944307-bot.github.io/kamonegi-house/**

![カモネギハウス 3D](og.jpg)

- ドラッグで回転、ホイール／ピンチで拡大
- 「🦆 メンバーを見る」を押すか、カモをタップするとメンバー紹介が出ます
- 頭の上の宝石の色は最高ランク（プラチナ・ダイヤ・マスター・プレデター）
- 「🌙 夜にする」で夜の景色に切り替え
